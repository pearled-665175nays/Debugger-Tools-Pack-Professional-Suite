## Features

## FAQ

**Q: What operating systems are supported?**
A: Debugger Tools Pack is fully compatible with Windows 10 and Windows 11 (both 32-bit and 64-bit editions). Kernel-mode debugging requires a properly configured driver signing environment.

**Q: The installation seems to hang at 50%. What should I do?**
A: This can sometimes occur due to antivirus interference. Please temporarily disable real-time protection, ensure you have a stable internet connection if the installer is downloading dependencies, and try running the installer as administrator again. If the issue persists, check the log file in the installation directory for specific error codes.

**Q: Does this support debugging .NET or managed code applications?**
A: Yes. The suite includes a managed debugger engine that integrates with the .NET runtime, allowing you to set breakpoints in both native and managed code within the same debugging session.
